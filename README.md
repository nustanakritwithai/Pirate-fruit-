# 🏴‍☠️ Pirate Fruit

เกมโอเพนเวิลด์แนว Blox Fruits สร้างด้วย **Three.js + TypeScript** เล่นบนเบราว์เซอร์

ตอนนี้จบ **Phase 5 — Combat**: หมัด/ดาบ + คอมโบ, Block, สกิล 3 ท่า, Knockback, ตัวเลขดาเมจ
ดูแผนพัฒนาทั้ง 12 Phase ได้ที่ [ROADMAP.md](ROADMAP.md)

## วิธีรัน

```bash
cd client
npm install
npm run dev
```

แล้วเปิด http://localhost:5173

## วิธีเล่น

### บนคอมพิวเตอร์

| ปุ่ม | การกระทำ |
|---|---|
| `W A S D` / ลูกศร | เดิน |
| `Shift` | วิ่ง (ใช้ Energy) |
| `Space` | กระโดด |
| `Q` | พุ่งหลบ (Dash — คูลดาวน์ 2.2 วิ ใช้ Energy 12) |
| `R` | สลับอาวุธ หมัด 👊 / ดาบ 🗡️ |
| `F` (ค้าง) | Block — ลดดาเมจเหลือ 30% แลก Energy 7 ต่อครั้งที่กัน |
| `1` `2` `3` | สกิล: 🌊 ฟันคลื่น / 🌀 วงจันทร์ / ⚡ พุ่งฟัน |
| `E` | สนทนากับ NPC ที่อยู่ใกล้ |
| คลิกซ้าย | ล็อกเมาส์เพื่อหมุนกล้อง (`Esc` ปลด) / คลิกระหว่างล็อก = โจมตีมอนสเตอร์ |
| ล้อเมาส์ | ซูมเข้า/ออก |

### ระบบต่อสู้ (Phase 4-5)

- **อาวุธ 2 ชนิด**: หมัด (เร็ว คอมโบไว) / ดาบ (แรง ระยะไกลกว่า) — สลับด้วย `R` หรือปุ่มอาวุธบนมือถือ
- **คอมโบ 3 จังหวะ**: ตีต่อเนื่องใน ~1.15 วิ ดาเมจเพิ่มทีละจังหวะ จังหวะสุดท้ายแรงพิเศษ + ผลักศัตรูกระเด็น (Knockback — บอสต้านทาน)
- **Block**: กด `F`/ปุ่ม 🛡️ ค้าง มีโล่แสงรอบตัว ลดดาเมจที่รับเหลือ 30% แลกพลังงาน
- **สกิล 3 ท่า** (มีคูลดาวน์ + ใช้ Energy): 🌊 **ฟันคลื่น** ยิงคลื่นตัดทุกตัวที่ขวางทาง (55 dmg),
  🌀 **วงจันทร์** ฟาดรอบตัว+ผลักกระเด็น (45 dmg), ⚡ **พุ่งฟัน** พุ่งไปหน้า 7 เมตรฟันตามทาง (65 dmg)
- **ตัวเลขดาเมจลอย** เหนือหัวศัตรูทุกครั้งที่ตี + HP ฟื้นเองเมื่อไม่โดนตี 6 วิ
- เกาะฝั่งตะวันออกมีแคมป์มอนสเตอร์: **ปูทะเลดุ (Lv.2)**, **โจรสลัดเร่ร่อน (Lv.4)** และ
  **บอส กัปตันหนวดดำ (Lv.10, HP 680)** พร้อมแถบเลือดบอสกลางจอ — ตายแล้วเกิดใหม่ที่แคมป์เดิม
- ผู้เล่น HP หมด → กลับหมู่บ้าน + ฟื้นเต็ม; ไม้ตาย (ปุ่มม่วง) ปลดล็อกใน Phase 7

### ตอนขับเรือ

| ปุ่ม | การกระทำ |
|---|---|
| `W/S` | เร่ง / ถอยและเบรก |
| `A/D` | เลี้ยวเรือ |
| `Q` หรือ `Shift` | Boost |
| `Space` | ทอด/ยกสมอ |
| `E` | ลงเรือได้ทุกที่ — จอดใกล้ท่า/ชายฝั่งจะลงบนบก กลางทะเลจะกระโดดลงว่ายน้ำ |

ลงน้ำแล้วตัวละครจะว่ายน้ำลอยที่ผิวน้ำ (กด `Space` เพื่อดันตัวขึ้นฝั่ง) ว่ายกลับมาใกล้เรือแล้วกด `E` เพื่อขึ้นเรืออีกครั้ง

## สิ่งที่มีใน Phase 1–3

- เกาะเริ่มต้นแบบ procedural (เนิน หาดทราย ต้นปาล์ม หิน ลัง) ล้อมด้วยทะเล
- กราฟฟิก **Mobile Realistic PBR**: ท้องฟ้าจำลองบรรยากาศจริง + environment map,
  พื้นเกาะ texture splatting 3 ชั้น (ทราย/หญ้า/หิน พร้อม normal map),
  น้ำทะเลคลื่นเคลื่อนไหวสะท้อนแสงอาทิตย์, ต้นปาล์ม/หิน/ลังใช้ texture จริง
- ปรับแต่งให้มือถือ: texture JPG 1K (~2.4MB), จำกัด pixel ratio, ลดความละเอียดเงาอัตโนมัติ
- ตัวละคร 3D (`Soldier.glb` จาก three.js examples) พร้อม animation Idle / Walk / Run
- กล้อง Third Person
- ระบบชน: พื้นเกาะ + สิ่งกีดขวาง
- HUD: มินิแมพ (มุมซ้ายบน แสดงเกาะ + ลูกศรทิศผู้เล่น), แถบ HP/Energy ขนาดกะทัดรัดกลางล่าง, พิกัด, FPS
- เซฟ/โหลดตำแหน่งอัตโนมัติ
- หมู่บ้านโจรสลัด บ้าน 4 หลัง Safe Zone และโคมไฟกลางคืน
- ท่าเรือที่เดินได้จริง พร้อมจุดเรียกและจอดเรือ
- สถานที่สำรวจ: หาดฝึกฝน สวนผลไม้ลึกลับ และศาลาบนเนิน
- NPC 4 ตัว: หัวหน้าหมู่บ้าน นายท่า นักวิจัยผลไม้ และร้านค้า พร้อมบทสนทนา
- วงจรกลางวัน/กลางคืน 12 นาที โดยบันทึกเวลาโลกลงในเซฟ
- ทะเลมีคลื่นจริงใน vertex shader สีตามชายฝั่ง และฟองคลื่นแบบประหยัด
- เมฆและธรรมชาติใช้ `InstancedMesh` เพื่อลด draw call
- Graphics Preset: ประหยัด / สมดุล / สวย โดยมือถือเลือกระดับเริ่มต้นอัตโนมัติ
- HUD แสดง FPS, draw calls, triangles และเวลาในเกม
- Safe Spawn แยกจากตำแหน่ง autosave ป้องกันการเกิดวนซ้ำกลางน้ำ
- อู่เรือผ่านบทสนทนากับกัปตันคราม มีเรือพายฟรีและเรือใบให้ซื้อ
- ระบบ ownership/เงิน/เรือที่เลือก พร้อมบันทึกใน localStorage
- เรือ procedural แบบ Mobile PBR พร้อมแรงเร่ง แรงต้าน การเลี้ยว ถอย Boost และ Anchor
- เรือเอียงตามคลื่น 4 จุด ชนเกาะเสีย HP แตก และรอเรียกใหม่ 10 วินาที
- Dock Zone ข้างท่า พร้อมขึ้น/ลงเรือและตำแหน่งลงที่ปลอดภัย
- Boat HUD และระบบปุ่มมือถือที่เปลี่ยนตามโหมดอัตโนมัติ

## Deploy ขึ้น Render

repo นี้มี [`render.yaml`](render.yaml) เป็น Blueprint พร้อม deploy เป็น Static Site:

1. เข้า [Render Dashboard](https://dashboard.render.com) → **New** → **Blueprint**
2. เลือก repo นี้ (branch ที่ต้องการ) — Render จะอ่าน `render.yaml` แล้วตั้งค่า build/publish ให้อัตโนมัติ
3. กด **Apply** รอ build เสร็จก็ได้ URL ใช้งานทันที

Build command และ publish directory (`client` → `npm run build` → `dist/`) ถูกกำหนดไว้ใน `render.yaml` แล้ว ไม่ต้องตั้งค่าเองในหน้าเว็บ
