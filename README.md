# 🏴‍☠️ Pirate Fruit

เกมโอเพนเวิลด์แนว Blox Fruits สร้างด้วย **Three.js + TypeScript** เล่นบนเบราว์เซอร์

ตอนนี้จบ **Phase 7 — ระบบผลไม้ + 2 ชุดสกิล + ร้านสุ่ม (Gacha)**: ไอเทม 1 ชิ้น = 1 ชุดสกิล
(อ้างอิง databook จาก Blox Fruits Wiki), ถืออาวุธ 1 + ผลไม้ 1 สลับชุดด้วยปุ่มอาวุธ/`R`,
สุ่มของที่ร้านดีลเลอร์ — ต่อยอดจาก Phase 6 (Level/Stats/Mastery/Quest)
— ดูแผน 12 Phase (v2) ที่ [ROADMAP.md](ROADMAP.md)

## วิธีรัน

```bash
cd client
npm install
npm run dev
```

แล้วเปิด http://localhost:5173

## วิธีเล่น

|---|---|

### Combat Framework (Phase 5)

- **State machine**: idle / attack1-4 / casting / blocking / stunned / knockback / knockdown / dead
- **คอมโบ M1 4 จังหวะ**: แต่ละจังหวะมี windup (ง้างก่อน hitbox เกิด) + recovery + movement lock,
  ตีครั้งเดียวต่อ swing, จังหวะ 4 = finisher แรงพิเศษ + Knockback, หน้าต่างต่อคอมโบ 1.2 วิ
- **2 ชุดสกิล (Phase 7)**: อาวุธที่ถือ 1 ชุด (ดาบ/ปืน/สไตล์ต่อสู้) + ผลไม้ที่ติดตั้ง 1 ชุด
  — ปุ่มอาวุธ/`R` สลับชุดที่ active; **M1 (คอมโบ) ใช้อาวุธที่ถือเสมอ**; ชุดสกิลอ้างอิง databook จาก Wiki
- **Block + Guard Meter**: กด `F`/ปุ่ม 🛡️ ค้าง — ลดดาเมจเหลือ 25% แลก Guard (แถบฟ้าใต้ Energy)
  Guard หมด → **Guard Break** สตัน 1.6 วิ; **ท่าหนักของบอส (ทุกตีครั้งที่ 3, มีแฟลชเตือน) บล็อกไม่ได้**
  — ทะลุโล่ + ผลักล้ม ต้องหลบด้วย Dash
- **สกิล data-driven** (หมวด style, มี castTime/คูลดาวน์/Energy): 🌊 ฟันคลื่น (55) / 🌀 วงจันทร์ (45+ผลัก) /
  ⚡ พุ่งฟัน (65) — เพิ่มสกิลใหม่ได้โดยแก้แค่ data ไม่แตะ combat core
- **Damage pipeline มาตรฐาน** จบด้วย Reward Contribution hook ซึ่งต่อ EXP/Mastery ของ Phase 6 แล้ว
- ตัวเลขดาเมจลอย + HP ฟื้นเองเมื่อไม่โดนตี 6 วิ
- แคมป์มอนสเตอร์ฝั่งตะวันออก: ปูทะเลดุ Lv.2, โจรสลัด Lv.4, **บอสกัปตันหนวดดำ Lv.10** (แถบเลือดกลางจอ)
  — มอนสเตอร์มี **leash** ไล่ไกลจากแคมป์เกินขอบเขตจะเดินกลับ ไม่ตามเข้าหมู่บ้าน
- ผู้เล่น HP หมด → กลับหมู่บ้าน + ฟื้นเต็ม; ไม้ตาย (ปุ่มม่วง) ใช้งานได้แล้ว (Phase 7)

### ระบบผลไม้ + ร้านสุ่ม (Phase 7)

- **ไอเทม 1 ชิ้น = 1 ชุดสกิล** (3 ท่า + ไม้ตาย) — อ้างอิง databook จาก [Blox Fruits Wiki](https://blox-fruits.fandom.com/)
  (ผลไม้ 41 ชนิด, ดาบ, ปืน, สไตล์ต่อสู้)
- **ร้านสุ่ม (Gacha)**: คุยกับดีลเลอร์ **หลิน** ที่สวนผลไม้ → จ่ายเหรียญสุ่มของตามความหายาก
  (Common → Mythic) แล้ว **ติดตั้ง** เพื่อใช้ชุดสกิลของชิ้นนั้น
- เริ่มเกมมีแค่ **สไตล์มือเปล่า** — ของอื่นต้องไปสุ่มที่ร้าน (บันทึก ownership อัตโนมัติ)
- **Skill Gameplay Databook (431 ท่า)** ที่ `combat/skillGameplay/generated.ts` — ค่าต่อสู้จริงของทุกท่า
  (archetype/ดาเมจ/ระยะ/CC/DoT/จำนวนฮิต) generate จากตาราง Wiki ด้วย `npm run gen:skills`
  · จูนท่าเด่น → `combat/skillGameplay/overrides.ts` · ปรับสูตร/classifier → `combat/skillGameplay/derive.ts`

### ระบบความก้าวหน้า (Phase 6)

- กำจัดมอนสเตอร์เพื่อรับ **Player EXP, Mastery EXP และ Coins**; มอนสเตอร์ที่ต่ำกว่าผู้เล่นมากจะให้ EXP ลดลง
- **ระบบสเตตัสสเกลเต็มตาม Blox Fruits Wiki**: Level สูงสุด **2800**, EXP curve `floor(2·L^2.3+84)`,
  3 Stat Points ต่อ Level, ลงได้สูงสุด **2800 แต้ม/สเตต** (max ได้ 3 สเตต)
- สเตตัส 5 แบบตาม Wiki: **Melee/มือเปล่า · Defense/พลังป้องกัน · Sword/ดาบ · Gun/ปืน · Blox Fruit/ผลไม้ปีศาจ**
  — Defense +5 HP · Melee +5 Energy + ดาเมจหมัด · Sword/Gun/Fruit ดาเมจสูงสุด ~78x; กด `K` หรือปุ่ม 📊
  เปิดหน้า Stats (โชว์ชื่อ+ผล+ค่าจริงตาม Wiki) · ค่ากลางอยู่ที่ `stats/` + `levels/` databook
- Mastery แยกตามอุปกรณ์ที่ทำดาเมจจริง โดยแบ่งรางวัล 70% ให้ชิ้นที่ทำดาเมจสูงสุด และ 30% ให้ชิ้นที่ปิดท้าย
- คุยกับ **หัวหน้ามะลิ** เพื่อรับ Quest กำจัดปู, โจรสลัด หรือบอส; รางวัลเข้าทันทีเมื่อทำครบ
- Progression และ Quest บันทึกอัตโนมัติใน `localStorage`; เงินเดิมจากระบบเรือถูก migrate มาใช้กระเป๋าเดียวกัน

### ตอนขับเรือ

| ปุ่ม | การกระทำ |
|---|---|
| `W/S` | เร่ง / ถอยและเบรก |
| `A/D` | เลี้ยวเรือ |
| `Q` หรือ `Shift` | Boost |
| `Space` | ทอด/ยกสมอ |
| `E` | ลงเรือได้ทุกที่ — จอดใกล้ท่า/ชายฝั่งจะลงบนบก กลางทะเลจะกระโดดลงว่ายน้ำ |

ลงน้ำแล้วตัวละครจะว่ายน้ำลอยที่ผิวน้ำ (กด `Space` เพื่อดันตัวขึ้นฝั่ง) ว่ายกลับมาใกล้เรือแล้วกด `E` เพื่อขึ้นเรืออีกครั้ง

### บนมือถือ (ระบบบังคับแบบ RoV)

| ส่วน | การกระทำ |
|---|---|
| จอยสติ๊กเสมือน (ฝั่งซ้าย แตะตรงไหนก็ได้) | เดิน |
| ปุ่ม 🏃 | เปิด/ปิดโหมดวิ่ง (ใช้ Energy) |
| ปุ่ม ⚔️ (ใหญ่ มุมขวาล่าง) | โจมตีหลัก (กดต่อเนื่อง = คอมโบ) |
| ปุ่ม 💨 | พุ่งหลบ (Dash) — มีวงแหวนคูลดาวน์บนปุ่ม |
| ปุ่ม ⬆️ | กระโดด |
| ปุ่มสกิล 3 ปุ่ม | สกิลของชุดที่ active (อาวุธหรือผลไม้) — ไอคอนเปลี่ยนตามชุด, มีวงแหวนคูลดาวน์ |
| ปุ่ม 🛡️ (ค้าง) | Block ลดดาเมจ |
| ปุ่มอาวุธ (ไอคอนชุด active) | สลับชุดสกิล อาวุธ ↔ ผลไม้ |
| ปุ่มไม้ตาย (วงม่วง) | ปล่อยไม้ตายของชุดที่ active (🔒 ถ้าชุดนั้นไม่มีไม้ตาย) |
| ลากนิ้วบนพื้นที่ว่างฝั่งขวา | หมุนกล้อง |
| ปุ่ม “คุยกับ…” ที่ปรากฏตามบริบท | สนทนากับ NPC |
| ขณะขับเรือ: จอยสติ๊ก | เร่ง ถอย และเลี้ยว |
| ขณะขับเรือ: ปุ่ม ⚡ | Boost |
| ขณะขับเรือ: ปุ่ม ⚓ | ทอด/ยกสมอ |

ตำแหน่งจะถูกเซฟอัตโนมัติทุก 3 วินาที (localStorage) — ปิดแล้วเปิดใหม่จะเกิดที่เดิม
ตกทะเลจะว่ายน้ำได้ (ไม่จมทันที) ว่ายกลับเข้าฝั่งหรือขึ้นเรือได้ ยกเว้นว่ายหลุดขอบโลกจึงถูกพากลับหมู่บ้าน

## สิ่งที่มีใน Phase 1–3

- เกาะเริ่มต้นแบบ procedural (เนิน หาดทราย ต้นปาล์ม หิน ลัง) ล้อมด้วยทะเล
- กราฟฟิก **Mobile Realistic PBR**: ท้องฟ้าจำลองบรรยากาศจริง + environment map,
  พื้นเกาะ texture splatting 3 ชั้น (ทราย/หญ้า/หิน พร้อม normal map),
  น้ำทะเลคลื่นเคลื่อนไหวสะท้อนแสงอาทิตย์, ต้นปาล์ม/หิน/ลังใช้ texture จริง
- ปรับแต่งให้มือถือ: texture JPG 1K (~2.4MB), จำกัด pixel ratio, ลดความละเอียดเงาอัตโนมัติ
- ตัวละคร 3D (`Soldier.glb` จาก three.js examples) พร้อม animation Idle / Walk / Run
- กล้อง Third Person
- ระบบชน: พื้นเกาะ + สิ่งกีดขวาง
- HUD: มินิแมพ (มุมซ้ายบน แสดงเกาะ + ลูกศรทิศผู้เล่น), แถบ HP/Energy ขนาดกะทัดรัดกลางล่าง, พิกัด, FPS
- เซฟ/โหลดตำแหน่งอัตโนมัติ
- หมู่บ้านโจรสลัด บ้าน 4 หลัง Safe Zone และโคมไฟกลางคืน
- ท่าเรือที่เดินได้จริง พร้อมจุดเรียกและจอดเรือ
- สถานที่สำรวจ: หาดฝึกฝน สวนผลไม้ลึกลับ และศาลาบนเนิน
- NPC 4 ตัว: หัวหน้าหมู่บ้าน นายท่า นักวิจัยผลไม้ และร้านค้า พร้อมบทสนทนา
- วงจรกลางวัน/กลางคืน 12 นาที โดยบันทึกเวลาโลกลงในเซฟ
- ทะเลมีคลื่นจริงใน vertex shader สีตามชายฝั่ง และฟองคลื่นแบบประหยัด
- เมฆและธรรมชาติใช้ `InstancedMesh` เพื่อลด draw call
- Graphics Preset: ประหยัด / สมดุล / สวย โดยมือถือเลือกระดับเริ่มต้นอัตโนมัติ
- HUD แสดง FPS, draw calls, triangles และเวลาในเกม
- Safe Spawn แยกจากตำแหน่ง autosave ป้องกันการเกิดวนซ้ำกลางน้ำ
- อู่เรือผ่านบทสนทนากับกัปตันคราม มีเรือพายฟรีและเรือใบให้ซื้อ
- ระบบ ownership/เงิน/เรือที่เลือก พร้อมบันทึกใน localStorage
- เรือ procedural แบบ Mobile PBR พร้อมแรงเร่ง แรงต้าน การเลี้ยว ถอย Boost และ Anchor
- เรือเอียงตามคลื่น 4 จุด ชนเกาะเสีย HP แตก และรอเรียกใหม่ 10 วินาที
- Dock Zone ข้างท่า พร้อมขึ้น/ลงเรือและตำแหน่งลงที่ปลอดภัย
- Boat HUD และระบบปุ่มมือถือที่เปลี่ยนตามโหมดอัตโนมัติ

## Phase 9A — เกาะพงไพรหมอก

- เกาะที่สองทางตะวันออกสำหรับ Level 15–30 พร้อมช่องทะเลให้เดินเรือจากเกาะเริ่มต้น
- ค่ายนักสำรวจ ท่าเรือ ซากวิหารโบราณ ลานผู้พิทักษ์ และถ้ำบอส
- มอนสเตอร์ใหม่ 2 ชนิด + บอสวานรพิษโบราณ พร้อมรางวัล EXP/Mastery/Coins
- NPC ใหม่ 4 คนและภารกิจใหม่ 4 งาน โดยใช้ Combat/Progression pipeline เดิม
- Minimap สลับแผนที่เกาะกับภาพรวมทะเลอัตโนมัติ และจุดเกิดแยกตามเกาะ
- Save v3 ย้ายข้อมูลจากเซฟเดิมอัตโนมัติ โดยไม่ลบตำแหน่ง เงิน เรือ หรือ Progression
- ฉากป่าใช้ `InstancedMesh` และหยุดจำลอง NPC/มอนสเตอร์ระยะไกลเพื่อคุมประสิทธิภาพมือถือ

## Phase 9B — เกาะทะเลทรายสุริยะ

- เกาะที่สามทางเหนือของเกาะพงไพรหมอกสำหรับ Level 31–50 พร้อมท่าเรือฝั่งใต้และเส้นทางเดินเรือต่อเนื่อง
- นครคาราวาน โอเอซิส ค่ายโจร เหมืองหิน พีระมิด และลานบอสผู้พิทักษ์สุริยะ
- มอนสเตอร์ใหม่ 3 ชนิด + บอส Level 48 พร้อมรางวัลผ่าน Reward/Progression pipeline เดิม
- NPC ใหม่ 4 คนและภารกิจใหม่ 4 งาน ครอบคลุมแมงป่อง โจร โกเลม และบอส
- Minimap ภาพรวมทะเลคำนวณขอบเขตจาก Island Registry จึงรองรับเกาะที่เพิ่มใหม่โดยอัตโนมัติ
- Save/checkpoint, dock/boat และน้ำตื้นรอบชายฝั่งรองรับครบสามเกาะโดยไม่ลบข้อมูลเดิม
- กระบองเพชร ปาล์ม และก้อนหินใช้ `InstancedMesh` พร้อม LOD ระยะไกลเพื่อรักษาเฟรมเรตมือถือ

## Phase 9C — เกาะเหมันต์คราม

- เกาะที่สี่ทางตะวันตกเฉียงเหนือของเกาะทะเลทรายสำหรับ Level 51–70 พร้อมท่าเรือฝั่งตะวันออกเฉียงใต้
- หมู่บ้านนักล่า ทะเลสาบน้ำแข็ง เหมืองคริสตัล ค่ายโจร และป้อมราชันน้ำแข็ง
- มอนสเตอร์ใหม่ 3 ชนิด + บอสราชันน้ำแข็ง Level 68 พร้อมท่าหนักแบบ unblockable
- NPC ใหม่ 4 คนและภารกิจใหม่ 4 งานผ่าน Combat/Reward/Progression pipeline เดิม
- Minimap, Save/checkpoint, dock/boat และน้ำตื้นชายฝั่งขยายเป็นสี่เกาะโดยใช้ Registry กลาง
- ต้นสน คริสตัล และสิ่งประกอบฉากใช้ `InstancedMesh` พร้อม LOD ระยะไกลสำหรับมือถือ

## Phase 9D — เกาะนภาวายุ

- เกาะที่ห้าทางตะวันตกของเกาะเหมันต์ครามสำหรับ Level 71–90 พร้อมท่าเรือฝั่งตะวันออก
- หมู่บ้านหน้าผา สวนเมฆลอย ค่ายโจร โรงตีผลึกพายุ และวิหารยอดเกาะ
- มอนสเตอร์ใหม่ 3 ชนิด + บอสเจ้าแห่งพายุนิรันดร์ Level 88 พร้อมท่าหนักแบบ unblockable
- NPC ใหม่ 4 คนและภารกิจใหม่ 4 งานผ่าน Combat/Reward/Progression pipeline เดิม

## Deploy ขึ้น Render

repo นี้พร้อม deploy เป็น **Static Site** บน [Render](https://render.com) ผ่าน Blueprint [`render.yaml`](render.yaml)

### วิธีที่ 1 — Blueprint (แนะนำ)

1. Push branch ที่ต้องการ deploy ขึ้น GitHub
2. เข้า [Render Dashboard](https://dashboard.render.com) → **New** → **Blueprint**
3. เลือก repo `Pirate-fruit-` และ branch (เช่น `claude/blox-fruits-three-js-roadmap-1f2f5u` หรือ PR branch)
4. Render อ่าน `render.yaml` แล้วตั้งค่าให้อัตโนมัติ:
   - **Root Directory:** `client`
   - **Build Command:** `npm install && npm run build`
   - **Publish Directory:** `dist` (เมื่อ rootDir = `client`)
   - **Node:** 22 (จาก `client/.node-version`)
5. กด **Apply** — รอ build เสร็จได้ URL เช่น `https://pirate-fruit.onrender.com`

### วิธีที่ 2 — Static Site แบบตั้งเอง

| ค่า | ตั้งเป็น |
|-----|----------|
| Environment | Static Site |
| Root Directory | `client` |
| Build Command | `npm install && npm run build` |
| Publish Directory | `dist` |
| Rewrite | `/*` → `/index.html` |

### ตรวจ build ก่อน deploy (เครื่อง local)

```bash
cd client
npm ci
npm run build
npm run preview   # เปิด http://localhost:4173
```

`dist/` ถูก gitignore — Render จะ build ใหม่ทุกครั้งที่ deploy
